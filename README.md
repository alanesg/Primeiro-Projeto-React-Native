# 📱 Primeiro Projeto React Native

Projeto desenvolvido durante a graduação em **Análise e Desenvolvimento de Sistemas**, com o objetivo de praticar e aprofundar conhecimentos em React Native, Expo e navegação entre telas.

Este projeto funciona como um laboratório de estudos, permitindo experimentar componentes, explorar funcionalidades e compreender melhor o desenvolvimento de aplicações mobile.

## 🚀 Tecnologias utilizadas

- React Native
- Expo
- JavaScript
- React Navigation
- Material Top Tabs Navigator
- React Navigation Native Stack

## 📚 O que estou praticando?

Durante o desenvolvimento, estou explorando:

- Criação e organização de componentes.
- Estruturação de telas.
- Navegação entre páginas.
- Utilização de abas superiores (Material Top Tabs).
- Navegação por meio de botões.
- Integração de bibliotecas externas.
- Organização de projetos com React Native e Expo.

## ⚙️ Como executar o projeto

1. Clone este repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Entre na pasta do projeto:

```bash
cd PrimeiroProjetoReactNative
```

3. Instale as dependências:

```bash
npm install
```

4. Inicie o Expo:

```bash
npx expo start
```
